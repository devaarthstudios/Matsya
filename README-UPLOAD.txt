Matsya website - upload steps
1. Unzip matsya-website.zip. You get a folder named Matsya.
2. On GitHub open the devaarthstudios.github.io repository (or the repo that serves your site), choose Add file > Upload files, drag the whole Matsya folder in, and commit.
3. Wait a minute. The pages open at https://devaarthstudios.github.io/Matsya/ and the privacy page at https://devaarthstudios.github.io/Matsya/privacy.html
